s-pay-mall-weixin

这是一个用于课程演示的微信公众号（测试号）对接服务，用来验证消息接收、签名校验与回调链路。

本地服务默认地址：http://127.0.0.1:8080/

使用前请确认以下配置

  1. 参考课程文档说明： https://articles.zsxq.com/id_9989gopludhm.html。 按文档注册并进入微信公众号测试平台： https://mp.weixin.qq.com/debug/cgi-bin/sandboxinfo?action=showinfo&t=sandbox/index。
  2. 修改 s-pay-mall-weixin 工程的 application-dev.yml： 微信公众号对接的 originalid 需要替换为你自己的。
  3. 使用 natapp 做内网穿透：在官网 https://natapp.cn/ 购买付费隧道（最低档即可）。Windows 用户下载 exe 版本放到本项目的 docs/natapp 文件夹。使用文档： https://natapp.cn/article/natapp_newbie。
  4. 确保 natapp 映射端口与本地 Spring Boot 端口一致（当前测试程序为 8080）。
  5. 最后参考课程说明，在微信公众号测试平台配置你的回调地址。例如课程填写： http://xfg-studio.natapp1.cc/api/v1/weixin/portal/receive/
